# Capstone

The final exercise asks you to build a small guessing-game implementation from the unfinished `exercises/src/capstone.rs` file.

Start with the fixed sample `GameRecord`. Add a ply clamp, selected-player rating scoring, and case-insensitive opening matching. The capstone test target checks these connected behaviors. Then use the main app's `api.rs`, `chess.rs`, and `web.rs` as references for adding archive loading, saved positions, and visible feedback to your own version.

The capstone solution in `solutions/capstone.rs` completes the exercise's tested functions. The larger application flow is described in [reference.md](/guide/reference#capstone-and-end-to-end-flow).
