# List every reviewable ply

## Goal

Build a guided inclusive range for a game that includes the starting position and final ply.

## Check

Run `capstone_easy`. It checks a game with moves and a game with no moves.

## Hint

The starting position is zero. Use an inclusive range so `move_count` itself is included.

## NOTE

This is the easy version of the capstone example. Read the NOTE in the Rust source to understand the expected behavior before changing it.
