# Calculate rating error

## Goal

Calculate how far a guess is from the actual Elo rating using a non-negative absolute error.

## Check

Run `elo_scoring_easy`. It checks guesses above and below the actual rating.

## Hint

The subtraction order should not change the size of the error. Use the integer absolute-value method.

## NOTE

This is the easy version of the guess the elo example. Read the NOTE in the Rust source to understand the expected behavior before changing it.
